
# Game Metadata ETL Pipeline

A Python-based data engineering project that extracts, parses, normalises, and validates game metadata from multiple sources.

## Data Sources

- Steam — JSON
- Xbox — XML
- PlayStation — Excel

## Current Features

- Multi-format feed parsing
- Canonical game model
- Platform-specific normalisation
- Data validation
- Accepted and rejected record classification
- Source-level error reporting

## Planned Features

- Duplicate detection
- Validation logging
- Image processing
- PostgreSQL integration
- RAWG API integration
- Power BI dashboard

## Technologies

Python, JSON, XML, openpyxl, PostgreSQL (planned), Power BI (planned).

## Project Status

In development.
